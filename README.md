# How to Cook（中餐）· 厨房小白版

这，一份从“为什么”讲起的中餐入门指南。

如果你觉得做菜做的一头雾水，知其然不知其所以然，
那么这是一份从原理开始讲起的厨房手册，也是一份将化学原理和实操，掰开揉碎教给你的做菜指南。

原理证实，过程正确，结果就不会有错。

## 核心模型：做菜在控制的三件事：热度/水分/调味

| 变量 | 你在控制什么 | 典型操作 |
|---|---|---|
| **热** | 多少热量、多快进入食材、进到多深 | 火力大小、油温、下锅顺序、切多大 |
| **水** | 食材里的水留住还是赶走 | 擦干、上浆、焯水、收汁、勾芡 |
| **味** | 以咸为主轴，再叠加鲜、酸、甜、辣、香 | 放盐时机、调料配比、出锅前尝 |

几乎每个步骤都能归到这三类里。比如：

- **肉切丝前要上浆** → 控制“水”：给肉表面裹一层保护膜，锁住水分，所以嫩。
- **炒青菜要大火** → 控制“热”和“水”：快速升温，菜还没来得及出水就熟了，所以脆。
- **叶菜最后放盐** → 控制“水”：盐会把菜里的水“吸”出来（渗透），早放就成了一盘汤。

读完 [原理篇](docs/01-principles.md)，后面的菜谱基本都能自己推出来。

## 这份指南的约定

- **重量用克。** 新手买一个厨房秤（几十块钱），是性价比最高的投资。先对重量有概念，才能为烹饪打好基础。
- **勺子：** 1 汤匙（大勺）≈ 15 ml，1 茶匙（小勺）≈ 5 ml。具体换算见 [调味系统](docs/03-seasoning.md#常用换算)。
- **火力：** 按家用燃气灶描述。电磁炉的“大火”通常不如燃气灶猛，需要更多预热时间。
- **时间只是参考，信号才是标准。** 每道菜都写了“判断信号”：看颜色、听声音、闻气味、看质地。时间和信号冲突时，相信你的眼睛。
- **数字是起点，不是答案。** 第一次照着做，然后根据口味调。调味宁少勿多，少了能补，多了很难救。

## 写在前面

几点需要说明：

- 数值（温度、配比、时间）尽量取了公认的范围，但家庭条件差别很大，请把它们当起点。
- 食品安全相关数值参考了通行的卫生标准。如果你有特殊健康状况（怀孕、免疫力低下、过敏等），以专业医生的建议为准。
- 手感类的东西（颠锅、判断火候），文字只能帮你知道“看什么”，真正学会靠多做。
