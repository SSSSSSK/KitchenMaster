# 02 · 最小厨房装备

原则：**先买能做 90% 家常菜的最少工具，缺什么再补。** 一开始买一堆，大部分会吃灰。

---

## 必备（没有就做不了）

| 工具 | 建议 | 为什么 |
|---|---|---|
| **不粘炒锅**（28–30 cm，带盖） | 新手第一口锅 | 不粘容错率高，炒蛋、煎鱼都不容易翻车。锅盖用来焖、防溅油、灭油火。 |
| **汤锅**（20–22 cm，带盖） | 不锈钢即可 | 煮面、煮汤、焯水、炖菜 |
| **菜刀** | 一把中式菜刀或 18–20 cm 厨师刀 | 一把锋利的刀比三把钝刀好用。钝刀更危险，因为要更用力，容易打滑。 |
| **砧板** | 两块：一块切生肉，一块切熟食和蔬菜 | 生熟分开，防交叉污染 |
| **锅铲** | 不粘锅配硅胶或木铲 | 金属铲会刮坏不粘涂层 |
| **厨房秤** | 精度 1 g | 调味和配比的基础，新手最值得买 |
| **量勺** | 一套，含 1 汤匙（15 ml）和 1 茶匙（5 ml） | 让配方可重复 |
| **几个碗** | 大中小各几个 | 装备好的料、调碗汁 |
| **蒸架或蒸笼** | 能放进汤锅或炒锅 | 蒸蛋、蒸鱼 |

---

## 很有用（第二批再买）

| 工具 | 用途 |
|---|---|
| 铁锅 | 火力更猛、更香，适合熟练以后。需要开锅和养护。 |
| 漏勺 | 捞面、捞焯水的菜 |
| 削皮刀 | 土豆、胡萝卜 |
| 擦丝器 | 切丝困难时的救星（土豆丝、胡萝卜丝） |
| 计时器 | 手机也行 |
| 厨房纸 | 擦干食材、吸油 |
| 保鲜盒 | 剩菜、备料 |

---

## 不粘锅使用规则

不粘锅是新手的好朋友，但有几个规矩：

- **不要空烧到很高温。** 涂层在过高温度下会分解。先放油再开火，或者中火预热一小会儿就下油。
- **不用金属铲、钢丝球。**
- **不要热锅直接冲冷水。** 温度骤变会让锅变形、涂层脱落。
- **涂层明显划花、起皮就换。**

## 铁锅（以后再说）

铁锅的好处是能承受更高温度，炒菜更香。但它会生锈、新锅要开锅、炒酸性食物容易掉色，对新手不友好。等你炒熟练了再考虑。

用铁锅的关键诀窍是 **“热锅凉油”**：先把空锅烧到很热（洒几滴水会立刻缩成水珠滚动），再倒油、晃匀，然后下料。锅足够热时，食材表面会迅速形成一层焦化层，就不容易粘。

## 基础调料清单

先备这些，能做本指南里所有菜：

**必备：**
- 盐
- 生抽（颜色浅，主要提供咸鲜）
- 老抽（颜色深，主要用来上色，咸度和生抽差不多但用量少）
- 香醋或陈醋
- 白糖或冰糖
- 料酒
- 食用油（花生油、菜籽油等）
- 淀粉（玉米淀粉或土豆淀粉）
- 葱、姜、蒜

**第二批：**
- 蚝油
- 郫县豆瓣酱
- 干辣椒、花椒
- 香油
- 白胡椒粉
- 八角、桂皮、香叶（炖菜用）
- 蒸鱼豉油

调料的具体用法见下一章。
