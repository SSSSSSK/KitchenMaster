# 03 · 调味系统

调味不是“放多少”的问题，而是“**每样调料在负责什么、什么时候放**”的问题。搞清楚分工，看到陌生菜谱也能大致判断它在干什么。

---

## 味道的结构

把一道菜的味道想成一个结构：

- **咸**是地基。没有它，其他味道都立不住。
- **鲜**让味道“厚”。来源：酱油、蚝油、肉、番茄、菌菇、鸡精味精。
- **酸**让味道“亮”，能解腻。
- **甜**让味道“圆”，能缓和咸和酸的尖锐感。很多不甜的菜也会放一点糖，就是这个原因。
- **辣、麻**是刺激，属于“加分项”。
- **香**来自油、葱姜蒜、发酵调料和美拉德反应（见 [原理篇](01-principles.md#五香从哪里来)）。

几个常用的平衡关系：

- 太咸 → 加一点糖或醋可以稍微缓和（但不能真的抵消，最好的办法是加食材稀释）
- 太酸 → 加一点糖
- 太腻 → 加一点醋
- 太寡淡 → 先检查盐够不够，再考虑加鲜味

## 常用调料：作用和放的时机

| 调料 | 负责什么 | 什么时候放 | 注意 |
|---|---|---|---|
| **盐** | 咸 | 见 [原理篇的放盐时机](01-principles.md#放盐的时机) | 有其他咸味调料时要减量 |
| **生抽** | 咸 + 鲜，少量上色 | 炒菜中段；沿着**热锅边**淋入更香 | 本身含盐约 15%–18% |
| **老抽** | 主要用来**上色** | 红烧、炒饭需要颜色时 | 少量就很深，先放半勺 |
| **蚝油** | 鲜 + 咸 + 一点甜 | 出锅前 | 加热太久鲜味会减弱 |
| **醋** | 酸、解腻、去腥 | 想留住酸味就**出锅前**加 | 加热会挥发掉一部分酸味 |
| **糖** | 甜、提鲜、平衡 | 和咸味调料一起 | 少量不吃出甜味，只会让味道更圆 |
| **料酒** | 去腥 | 肉下锅后、锅最热时沿锅边淋 | 要让它在高温下迅速蒸发 |
| **淀粉** | 上浆、勾芡 | 腌肉时；出锅前勾芡 | 勾芡前要用冷水调开 |
| **葱** | 香 | 葱白耐热，先下；葱绿易蔫，出锅前撒 | — |
| **姜** | 去腥、辛香 | 一开始爆香 | 切片去腥，切末出味更快 |
| **蒜** | 辛香 | 爆香；或出锅前放（蒜味更冲） | **很容易焦**，焦了发苦。用中小火 |
| **干辣椒、花椒** | 辣、麻、香 | 一开始用温油小火炸香 | 辣椒变深红棕色就好，**发黑就苦了** |
| **郫县豆瓣酱** | 咸、鲜、辣、红色 | 用油小火炒出红油 | 很咸，放了基本不用另外加盐。剁细更好出味 |
| **香油** | 香 | **出锅前**或凉拌 | 不要用来高温炒 |
| **白胡椒粉** | 辛辣、去腥 | 汤、蛋、肉 | — |
| **鸡精/味精** | 鲜 | 出锅前 | 适量食用没有问题；鸡精本身含盐 |

## 下料的通用顺序

绝大多数中式炒菜都遵循这个顺序。理解了它，就不用每次死记步骤：

```
1. 热锅
2. 倒油
3. 爆香：葱白、姜、蒜、干辣椒、花椒（中小火，别焦）
4. 下主料（通常是肉，先炒到变色）
5. 料酒（沿锅边，趁热）
6. 酱油类（生抽、老抽）
7. 下配料（蔬菜）
8. 调味：盐、糖
9. 勾芡（如果需要）
10. 出锅前：醋、香油、蚝油、葱绿
```

**逻辑：** 耐热的、需要激发香味的先下；怕热的、要保留风味的后下。

## 碗汁：新手快炒的救星

快炒的菜从下主料到出锅可能就一两分钟。这么短的时间里一样样去拿调料、量调料，手忙脚乱，菜早就炒老了。

**解决办法：提前把所有调料（包括淀粉）在一个碗里调好，叫“碗汁”。** 到了那一步，搅一搅，一次性倒进锅里。

这一个习惯能解决新手一半的手忙脚乱。

注意：淀粉会沉底，倒之前**一定要再搅一下**。

## 经典味型：起步配比

下面是几个常见味型的**起步比例**，按勺计（同一把勺子量）。第一次照做，然后按口味调。

### 糖醋（如糖醋排骨、糖醋里脊）

一个好记的家常比例：**料酒 1 : 醋 2 : 糖 3 : 生抽 4 : 水 5**

酸甜明显，偏甜。喜欢酸一点就多加醋。

### 鱼香（如鱼香肉丝、鱼香茄子）

- 糖 : 醋 : 生抽 ≈ **1 : 1 : 1**
- 加料酒少许、淀粉 1 茶匙、水 2–3 汤匙
- 配合大量葱姜蒜末 + 泡椒或郫县豆瓣

特点：咸、甜、酸、辣都有，而且平衡。并没有鱼，“鱼香”来自川菜烹鱼的调料组合。

### 荔枝味（宫保鸡丁）

- 糖 : 醋 : 生抽 ≈ **1 : 1 : 1**，和鱼香接近
- 加少许老抽上色，淀粉 1 茶匙，水 2–3 汤匙
- 区别在香味来源：不放豆瓣和泡椒，靠干辣椒、花椒炝锅出香

特点：入口先有微甜，后有微酸，像荔枝。

### 凉拌汁（万能版）

- 生抽 2 : 醋 2 : 糖 0.5–1 : 香油 1
- 加蒜末，可选辣椒油

### 红烧

- 生抽 + 老抽（上色）+ 糖（或冰糖）+ 料酒
- 可选香料：八角、桂皮、香叶
- 用水或热水没过食材，焖到软，最后大火收汁

### 葱油

- 生抽 2 : 老抽 1 : 糖 1
- 配合小火熬好的葱油

## 常用换算

不同调料密度不同，同样一勺，重量不一样：

| 调料 | 1 汤匙（15 ml） | 1 茶匙（5 ml） |
|---|---|---|
| 盐 | — | 约 5–6 g |
| 白糖 | 约 12 g | 约 4 g |
| 生抽 | 约 16–17 g | 约 5–6 g |
| 淀粉 | 约 8–9 g | 约 3 g |
| 油 | 约 13–14 g | 约 4–5 g |

1 汤匙 = 3 茶匙。

“少许”“一小撮”大概是用拇指和食指捏一下的量，盐约 0.5–1 g。
