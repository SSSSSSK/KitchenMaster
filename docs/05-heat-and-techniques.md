# 05 · 火候与基本技法

“火候”听起来玄，本质就是两件事：**热量给多少**，**给多久**。不同技法，就是用不同的介质（锅、油、水、蒸汽）和不同的速度把热量送进食材。

---

## 火力

| 火力 | 燃气灶的样子 | 典型用途 |
|---|---|---|
| **大火** | 火焰铺满锅底，往锅边窜 | 炒青菜、收汁、烧开水 |
| **中火** | 火焰刚好碰到锅底，不往外窜 | 大部分炒菜、煎 |
| **小火** | 火苗小，离锅底有点距离 | 炒酱、熬葱油、炖、焖 |

电磁炉功率通常比燃气灶小，大火要多预热一会儿，炒菜时每次下的量更要少。

---

## 用耳朵和眼睛判断

时间只是参考。这些信号更可靠：

| 信号 | 说明 |
|---|---|
| 下料瞬间“滋啦”一声 | 油温够了 ✅ |
| 下料没什么声音 | 油温太低，食材会吸油、粘锅 |
| 声音从清脆的“滋滋”变成闷闷的“咕嘟” | 锅里出水了，在“煮”而不是“炒”。下得太多，或火不够 |
| 收汁时声音变成“噼啪”响 | 水快干了，只剩油在响。**马上关火或出锅** |
| 蒜末边缘微微发黄、闻到香味 | 爆香完成，下一步 |
| 蒜末变成深褐色 | 焦了，会苦 |

## 八种基本技法

### 1. 炒

**介质：** 锅 + 少量油。**特点：** 高温、快速、不停翻动。

- **清炒**：直接炒，如炒青菜。
- **滑炒**：肉先上浆，在中温油里划散至八成熟盛出，最后回锅。如青椒肉丝。详见 [刀工与备料](04-knife-and-prep.md#滑炒家庭版)。
- **煸炒（干煸）**：中火慢慢炒，把食材里的水逼出来，变干变香。如干煸豆角。

关键：**锅要热，量要少**。下太多就会变成煮（见 [原理篇](01-principles.md#锅里放太多--从炒变成煮)）。

### 2. 煎

**介质：** 锅 + 薄层油。**特点：** 食材平放，一面一面地加热上色。

- 锅和油要先热。
- 食材下锅后**不要急着翻动**。蛋白质刚接触锅时会粘住；等表面形成焦壳，它会自己松开。这时候轻轻推一下能动了，再翻面。
- 一直粘着推不动，说明还没好，或者锅温不够。

### 3. 煮

**介质：** 水。**特点：** 最高 100 °C，温和，不会焦，但也不会有焦香。

### 4. 焯水

把食材放进水里短暂加热再捞出。有两种，目的完全不同：

| | 蔬菜焯水 | 肉焯水 |
|---|---|---|
| **下锅时机** | **水开后**下 | **冷水**下锅 |
| **目的** | 预熟、保持颜色、去掉涩味 | 把血水和杂质逼出来，去腥 |
| **时间** | 很短，几十秒到 1–2 分钟 | 水开后再煮 2–3 分钟，撇去浮沫 |
| **之后** | 捞出过冷水，停止加热、保持脆绿 | 捞出用温水冲洗干净 |

- 菠菜、苋菜这类涩味明显的菜，焯一下能去掉不少草酸。
- 西兰花、豆角这类不易熟的菜，先焯再炒，炒的时间就短，颜色更好。
- 肉为什么要冷水下锅？冷水慢慢升温，表面的蛋白质不会立刻凝固封住，里面的血水才能被逼出来。

### 5. 蒸

**介质：** 蒸汽（约 100 °C）。**特点：** 温和、均匀、保留原味、不会焦。

- 蒸鱼、蒸肉：**水烧开后再放上去**，时间才可控。
- 蒸蛋：要用中小火，见 [蒸蛋羹](../recipes/03-steamed-egg.md)。
- 锅里的水要够，蒸到一半烧干了很危险。

### 6. 炖、焖、烧

**介质：** 汤汁，小火长时间。**用于：** 结缔组织多的“韧”肉（见 [原理篇](01-principles.md#两类肉两种做法)）。

- 保持**微沸**：汤面微微冒小泡就行，不是剧烈翻滚。大滚会让肉更柴、汤更浑。
- **红烧**的典型流程：先煎或炒上色 → 加调料炒香 → 加水没过食材 → 小火焖到软 → 开大火收汁。
- 收汁之前，汤汁里的盐还没浓缩，**这时候尝起来应该略淡**。

### 7. 勾芡

用淀粉把汤汁变稠，裹在食材上。

1. 调**水淀粉**：淀粉 1 : 冷水 2–3。一定要用冷水，热水会直接把淀粉烫成疙瘩。
2. **汤汁沸腾时**倒入。淀粉要加热到一定温度才会变稠，汤不开就不会稠。
3. **边倒边搅，分 2–3 次加**，看稠度够了就停。一次全倒很容易过稠或结块。
4. 倒之前再搅一下水淀粉，因为淀粉会沉底。

薄芡：汤稍微有点挂勺（如蛋花汤、麻婆豆腐的第一次勾芡）。厚芡：汁能紧紧裹在食材上（如糖醋里脊）。

### 8. 炸（新手先少做）

**介质：** 大量油。危险度最高。如果要做：

- 油**不要超过锅的 1/3**。
- 食材必须**擦干**。
- 旁边放好锅盖。
- 绝对不能离开。

---

## 收汁：最容易翻车的最后一步

很多菜前面都对，最后收汁糊了。原因是：汤汁越少，温度升得越快；如果汁里有糖，糖到一定温度会迅速焦化变苦。

- 收汁时**人不要离开**。
- 不停用铲子推动，让汁均匀地裹在食材上。
- 汤汁变得浓稠、冒大泡、开始“噼啪”响时，**立刻关火**。余温还会继续收一点。

---

## 油锅着火怎么办

**记住：不能泼水。** 水遇到着火的油会瞬间汽化，把燃烧的油炸得到处都是。

1. **关火。**
2. **盖上锅盖**（隔绝氧气）。
3. **不要端着锅跑。**
4. 等它完全冷却再开盖。

如果火势控制不住，离开厨房，打 119。
