# 06 · 排障手册

菜做砸了，先别慌。按现象找到对应的条目，看看是哪个变量出了问题：**热**、**水**，还是**味**。

| [出水、炒成一锅汤](#出水炒成一锅汤) | 下太多；火太小；盐放早了 | 热 + 水 |

## 粘锅

**原理：** 蛋白质刚接触锅面时会和锅“粘”在一起。锅足够热、表面形成焦化层后，它会自己松开。

- 锅和油都要先热，再下料
- 下锅后**先别动**，等它自己能被推动了再翻
- 肉、鱼表面擦干
- 新手用不粘锅

## 出水、炒成一锅汤

**原理：** 锅温掉到 100 °C 以下，食材慢慢加热、细胞破裂出水；盐也会把水拉出来。详见 [原理篇](01-principles.md#二水留住还是赶走)。

- 大火
- 一次少下一点，分批炒
- 叶菜最后放盐
- 洗过的菜沥干
- 已经出水了：把菜捞出，大火把汤收干，再倒回去翻一下

## 不香、没有焦香

**原理：** 美拉德反应需要表面温度超过约 140 °C，而表面有水时温度卡在 100 °C 左右。

- 擦干食材
- 锅烧热
- 别挤，分批
- 爆香葱姜蒜时要等香味出来再下一步

## 肉又柴又硬

**原理：** 瘦肉加热过头，纤维收缩、挤出水分。

- 炒肉：**上浆 + 滑炒，变白就盛**，见 [上浆](04-knife-and-prep.md#上浆让肉变嫩的核心技术)
- 切肉逆纹
- 鸡胸换成鸡腿肉
- 回锅时间要短

## 炖了很久肉还是硬

**原理：** 结缔组织转化成明胶需要时间，这个过程不能跳过。

- 继续炖，或换高压锅
- 保持微沸，不要大滚

## 发苦、糊味

**原理：** 蒜、干辣椒、糖、豆瓣酱都在较低的温度下就会焦化发苦。

| 焦的东西 | 预防 |
|---|---|
| 蒜 | 中火，变微黄就下一步 |
| 干辣椒、花椒 | 冷油小火下锅，棕红就停 |
| 糖（糖色、收汁） | 不离开锅；颜色一到立刻下一步 |
| 豆瓣酱 | 小火炒 |

**焦了怎么办：** 少量可以挑出来；如果苦味已经扩散到油里，只能倒掉重来。

## 太咸

**原理：** 盐、生抽、蚝油、豆瓣、鸡精都含盐，叠加起来很容易超。收汁也会浓缩咸度。

**补救：**

- **最有效：加食材稀释。** 炒菜加没调味的配菜，炖菜加水、加土豆、加豆腐
- 加一点糖或醋，可以让咸味**感觉**没那么冲（但盐没有变少）
- “放土豆片吸盐”的效果很有限，本质还是靠稀释

**预防：** 有咸味调料时先不放盐，出锅前尝了再说。

## 太淡、没味道

- 先确认**盐够不够**。大多数“没味道”其实是咸度不够
- 盐够了还是寡淡：加一点鲜味（生抽、蚝油）、一点酸（醋）或一点香（香油、葱花）
- 调料挂不住：最后勾一点薄芡，让汁裹在食材上

## 溅油

**原理：** 水遇热油瞬间汽化，把油炸飞。

- 食材沥干、擦干
- 锅洗完烧干再倒油
- 食材从靠近自己的锅边**滑**进去，不要扔
- 准备锅盖，溅得厉害时可以先盖上
- 被溅到：立刻用流动的凉水冲 15–20 分钟

## 外面焦了里面生

**原理：** 热从外往里传需要时间，厚度翻倍，时间约变 4 倍。

- 切薄一点，大小一致
- 先大火上色，再转中小火，或盖盖焖一会儿让中间熟透
- 厚的肉块：煎好表面后加少量水，盖盖焖

## 芡汁结块或太稠

- 水淀粉要用**冷水**调，倒之前**再搅一下**
- 汤汁**沸腾时**倒，边倒边搅
- **分次**加
- 太稠了：加一点开水，搅匀
