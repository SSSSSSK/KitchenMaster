# 05 · 番茄蛋花汤

> 难度 ★ · 15 分钟 · 2–3 人份
> **新技能：** 煮汤、勾薄芡、打出漂亮的蛋花

## 为什么这样做

- **番茄先用油炒**：番茄的红色素溶于油不溶于水。先用油炒，汤会更红、更浓、番茄味更足。
- **先勾薄芡**：汤有了一点稠度，蛋花能浮在上面，不会沉底，口感也更滑。
- **汤要滚着下蛋液**：蛋液遇到高温瞬间凝固成片，才是蛋花。汤不够热，蛋液会散开，汤变浑。
- **倒完先别搅**：等几秒钟让蛋花定型，再轻轻推。马上搅就碎成絮了。

## 用料

| 食材 | 用量 |
|---|---|
| 番茄 | 1–2 个（约 250 g） |
| 鸡蛋 | 2 个 |
| 水 | 800 ml |
| 盐 | 约 5–6 g |
| 水淀粉 | 淀粉 1 汤匙 + 冷水 2–3 汤匙 |
| 油 | 1 汤匙 |
| 香油、葱花、白胡椒粉 | 少许 |

## 步骤

1. 番茄切小块。鸡蛋打散。调好水淀粉。
2. 锅里倒油，中火，下番茄，炒 **2–3 分钟**。
   ✅ 信号：番茄变软烂，油变成红色。
3. 加水，大火烧开，转中火煮 **3–5 分钟**。
4. 加盐，尝一下。
5. 水淀粉**再搅一下**，一边搅汤一边慢慢淋进去。
   ✅ 信号：汤稍微有点挂勺，不用很稠。
6. 保持汤**滚开**。把蛋液从高处沿着筷子**细细地转圈倒进去**。
7. **停 3–5 秒**，等蛋花浮起来、定型，再用勺子轻轻推一下。
8. 关火，淋香油，撒葱花和白胡椒粉。

## 常见翻车

| 现象 | 原因 | 解决 |
|---|---|---|
| 蛋花碎成絮、汤浑 | 汤不够开；倒得太快；倒完马上搅 | 大火保持滚开；细流慢倒；等几秒再推 |
| 蛋花结成大坨 | 一次倒太多 | 细流转圈倒 |
| 汤没有番茄味、颜色淡 | 番茄没炒透 | 炒到软烂出红油 |
| 芡太稠，像糊 | 水淀粉一次加太多 | 分次加；稠了就加点开水 |

## 举一反三

紫菜蛋花汤：番茄换成一小把紫菜，烧开后放，加几只虾皮提鲜。其余步骤一样。
