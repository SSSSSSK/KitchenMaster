# 13 · 麻婆豆腐

> 难度 ★★★ · 30 分钟 · 2–3 人份
> **新技能：** 盐水焯豆腐、炒肉末到酥香、分次勾芡

## 为什么这样做

- **豆腐先用盐水焯**：盐让豆腐表面的蛋白质收紧，豆腐变得更结实，后面不容易碎；也能去掉豆腥味，顺便给豆腐一点底味。
- **肉末炒到酥**：把肉末里的水分炒干、表面微焦，才香。没炒透的肉末吃起来是“水煮”的味道。
- **豆瓣小火炒出红油**：同 [鱼香肉丝](11-yuxiang-pork.md)。
- **煮几分钟让豆腐入味**：豆腐本身没什么味道，要在汤汁里待一会儿。
- **分次勾芡**：一次加太多水淀粉，容易结团，芡也不均匀。分 2–3 次加，每次轻推，芡汁才能均匀裹住每一块豆腐，又红又亮。
- **推，不要翻炒**：用铲背从锅边往中间推，豆腐才不会碎。
- **花椒粉最后撒**：花椒的麻香容易挥发，出锅后再撒最香。

## 用料

| 食材 | 用量 |
|---|---|
| 嫩豆腐（南豆腐） | 1 盒（约 400 g）。新手别用内酯豆腐，太嫩易碎 |
| 牛肉末（或猪肉末） | 80 g |
| 郫县豆瓣酱 | 1.5 汤匙，剁细 |
| 豆豉（可选） | 1 茶匙，剁碎 |
| 辣椒面（可选） | 1 茶匙 |
| 姜、蒜 | 各少许，切末 |
| 蒜苗或葱花 | 少许 |
| 花椒粉 | 1/2–1 茶匙，现磨更好 |
| 生抽 | 1 茶匙 |
| 水或高汤 | 200 ml |
| 水淀粉 | 淀粉 1 汤匙 + 冷水 3 汤匙 |
| 油 | 2 汤匙 |
| 盐（焯豆腐用） | 1 茶匙 |

## 步骤

1. 豆腐切成约 **2 cm 的块**。
2. 锅里烧水，加 **1 茶匙盐**，水**微开**（别大滚）时放入豆腐，**小火煮 1–2 分钟**。捞出备用，或者就泡在热盐水里。
3. 另起锅，倒油，中火，下肉末，炒散，继续炒约 **3 分钟**。
   ✅ 信号：肉末变干，颜色变深，有点焦黄，闻到肉香。
4. 转**小火**，下豆瓣酱、豆豉、辣椒面，炒约 **1 分钟**。
   ✅ 信号：油变红。
5. 下姜末、蒜末，炒香。
6. 加水或高汤，烧开。
7. 豆腐沥干，**轻轻滑进锅里**，加生抽。
8. 中小火煮 **3–4 分钟**，用**铲背轻推**，不要翻炒。
9. 尝一下咸淡。豆瓣已经很咸，**一般不用加盐**。
10. 水淀粉**搅匀**，**分 2–3 次**淋入，每次淋完都轻推几下，等汤汁再次冒泡再加下一次。
    ✅ 信号：汤汁浓稠、红亮，裹在豆腐上，锅底只剩少量汁。
11. 盛出，撒花椒粉、蒜苗或葱花。

## 常见翻车

| 现象 | 原因 | 解决 |
|---|---|---|
| 豆腐碎了 | 翻炒了；没焯水；豆腐太嫩 | 只推不翻；盐水焯；用南豆腐 |
| 太咸 | 豆瓣多，又加了生抽和盐 | 豆瓣减量；尝过再决定 |
| 芡汁结块 | 一次倒太多；水淀粉没搅 | 分次加；倒前搅 |
| 颜色暗、不红亮 | 豆瓣没炒出红油 | 小火多炒一会儿 |
| 肉末发柴没香味 | 没炒干 | 炒到变干、微焦 |
