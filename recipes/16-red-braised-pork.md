# 16 · 红烧肉

> 难度 ★★★★ · 约 1.5 小时 · 3–4 人份
> **新技能：** 煸油、炒糖色、焖、收汁

这道菜把前面学过的几乎所有东西都用上了，适合作为“毕业作品”。

## 为什么这样做

- **用带皮五花肉**：肥瘦相间。长时间焖煮后，肥肉和猪皮里的胶原蛋白变得软糯，瘦肉因为有脂肪包裹也不柴。
- **先煸出油**：把多余的油脂逼出来，吃起来不腻，表面也带点焦香。
- **炒糖色**：糖在油里加热会焦糖化，变成红亮的颜色和焦糖香。这是红烧肉“红”的来源。但糖从“刚好”到“焦苦”只差几十秒，所以单列为难点。
- **加热水**：锅里的温度不会一下掉下来，能很快回到沸腾，焖煮的过程更连贯。
- **最后收汁**：汤汁里的糖和胶质浓缩，紧紧裹在肉上，发亮。

## 用料

| 食材 | 用量 |
|---|---|
| 带皮五花肉 | 500 g |
| 冰糖 | 30 g（炒糖色用） |
| 生抽 | 2 汤匙 |
| 老抽 | 1 汤匙 |
| 料酒 | 2 汤匙 |
| 姜 | 4 片 |
| 葱 | 2 段 |
| 八角 | 2 个 |
| 桂皮 | 1 小块 |
| 香叶 | 2 片 |
| 热水 | 适量，没过肉 |
| 油 | 1 汤匙 |

## 步骤

### 处理肉

1. 五花肉切成 **2.5–3 cm 的块**。
2. 冷水下锅，加 2 片姜、1 汤匙料酒，烧开后煮 **2–3 分钟**，撇去浮沫。
3. 捞出，温水冲净，**擦干**。

### 煸油

4. 锅里放 1 汤匙油，**中小火**，下肉块，慢慢煸炒 **5–8 分钟**。
   ✅ 信号：表面微微焦黄，锅里出了不少油。
5. 盛出肉块。把锅里的油倒出来，**只留约 1 汤匙**。

### 炒糖色

6. **小火**，放冰糖，不停搅动。
7. 糖会经历：融化 → 冒大泡 → 泡变小变密 → **颜色变成枣红色**。约 2–4 分钟。
   ✅ 信号：枣红色、琥珀色，有焦糖香。
   ⚠️ 变成**深褐发黑、冒黑烟、有苦味**就是炒过了，只能洗锅重来。
8. 颜色一到，**立刻倒入肉块**，快速翻炒，让每块肉都裹上糖色。
   ⚠️ 熬化的糖温度非常高，溅到皮肤上会严重烫伤。肉块要擦干，下锅动作轻一点。

> **新手简化版：** 怕炒糊的话，可以跳过第 6–8 步：把肉块直接下锅，冰糖和其他调料一起加，颜色靠老抽。颜色和香味稍差，但不会失败。

### 焖

9. 下姜、葱、八角、桂皮、香叶，炒出香味。
10. 沿锅边淋 1 汤匙料酒，加生抽、老抽，翻匀。
11. 加**热水**，没过肉块。
12. 大火烧开，转**小火**，盖盖焖 **60 分钟**。中途翻动一两次，看看水够不够。
    这时汤汁尝起来应该**略淡**，因为后面还要收汁。

### 收汁

13. 夹出香料。尝一下，看是否需要加一点盐。
14. 开盖，**大火收汁**，不停翻动。
    ✅ 信号：筷子能轻松插透肉皮；汤汁变得浓稠，冒大泡，裹在肉上发亮。
    ⚠️ 这一步**不要离开**，糖多的汁很容易糊。
15. 关火，装盘。

## 常见翻车

| 现象 | 原因 | 解决 |
|---|---|---|
| 发苦 | 糖色炒过了 | 无法补救。下次用简化版，或颜色到枣红立刻下肉 |
| 肉硬、咬不动 | 焖的时间不够 | 继续焖 |
| 太腻 | 煸油不够；油没倒掉 | 多煸一会儿；出锅前撇掉表面的浮油 |
| 颜色淡 | 糖色太浅；老抽少 | 收汁前补一点老抽 |
| 糊底 | 收汁时离开了 | 不要离开 |
